Skriuw — Install

Debian / Ubuntu (apt)

curl -fsSL https://skriuw.github.io/packages/apt/key.gpg | sudo gpg --dearmor -o /usr/share/keyrings/skriuw.gpg
echo "deb [signed-by=/usr/share/keyrings/skriuw.gpg] https://skriuw.github.io/packages/apt stable main" | sudo tee /etc/apt/sources.list.d/skriuw.list
sudo apt update && sudo apt install skriuw

Fedora / RHEL / openSUSE (dnf)

sudo dnf config-manager addrepo --from-repofile=https://skriuw.github.io/packages/rpm/skriuw.repo
sudo dnf install skriuw

Arch (AUR)

yay -S skriuw-bin   # or: paru -S skriuw-bin

macOS (Homebrew)

brew install --cask skriuw/tap/skriuw

Windows (Scoop)

scoop bucket add skriuw https://github.com/skriuw/scoop-bucket
scoop install skriuw

Direct downloads

Download macOS, Windows, Debian/Ubuntu, RPM, or AppImage assets from GitHub Releases.

Winget and Snap are published only after their respective store submissions succeed. They are intentionally not listed as current install channels here.
